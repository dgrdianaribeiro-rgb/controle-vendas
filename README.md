# Controle de Vendas e Cobranças

Painel de vendas, clientes, produtos, parcelas, pagamentos e contas a pagar — feito para acompanhar vendas de Boticário, Natura, Eudora e Avon.

Publicado via GitHub Pages a partir da branch `main`. Abra `index.html` (ou o link do site) no navegador — os dados ficam salvos só no seu aparelho (localStorage). Use **Ajustes → Exportar/Importar** para levar os dados para outro aparelho ou fazer backup.

Não suba dados reais de clientes neste repositório — ele é público. Guarde qualquer backup (`.json`) fora do controle de versão.
